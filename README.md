# 阿斯西尼布（Asciminib）与 BCR-ABL 结合研究

本仓库汇总了阿斯西尼布（Asciminib，PubChem CID: 72165228）与 BCR-ABL 激酶野生型及 M472V 突变体相互作用的多尺度计算分析。文档涵盖了
结构准备、分子对接、分子动力学（MD）以及自由能微扰（FEP）等流程，详见 `docs/docking_asciminib_bcr_abl.md`；关键指标与结论浓缩于
 `docs/final_results.md`。

## 仓库结构

- `docs/`：研究背景、模型准备、模拟设定与结果分析文档。
- `data/`：预留用于存放补充的结构或轨迹文件（当前为空）。
- `scripts/`：预留用于后续分析所需的脚本（当前为空）。
